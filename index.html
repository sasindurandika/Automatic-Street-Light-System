Project Overview

This project demonstrates a simple and practical Automatic Street Light System that turns ON the light when it is dark and turns OFF during daytime. It helps in saving electricity and is built using basic components available in the university lab.

Key Features

🌞 Day/Night Detection

Automatically detects ambient light level using LDR sensor.

💡 Automatic Control

Controls the street light based on real-time light conditions.

📊 Real-time Monitoring

Displays sensor values through Serial Monitor.

🔋 Energy Saving

Reduces unnecessary power consumption.

Arduino Code


// Automatic Street Light System
const int LDR_PIN = A0;
const int LED_PIN = 13;
const int THRESHOLD = 500;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Automatic Street Light System Started");
}

void loop() {
  int ldrValue = analogRead(LDR_PIN);
  
  Serial.print("LDR Value: ");
  Serial.println(ldrValue);

  if (ldrValue < THRESHOLD) {
    digitalWrite(LED_PIN, HIGH);   // Night → ON
    Serial.println("→ NIGHT: Street Light ON");
  } else {
    digitalWrite(LED_PIN, LOW);    // Day → OFF
    Serial.println("→ DAY: Street Light OFF");
  }
  delay(500);
}

Results & Conclusion

The system performed successfully during testing. When the LDR was covered (simulating night), the LED turned ON automatically. When exposed to light, the LED turned OFF.
